# Python Source Code Overview

1. **[`password_logic.py`](../password_logic.py)** — Character scanner, repetition tracker, prohibited substring checker, password masker, ASCII strength bar generator, and batch evaluator.
2. **[`database.py`](../database.py)** — SQLite persistence for configurable policy rules and masked validation logs.
3. **[`app.py`](../app.py)** — Flask application for interactive checking, batch testing, policy editing, audit logs, and CSV export.
4. **[`tests/test_password.py`](../tests/test_password.py)** — Automated `unittest` suite.
