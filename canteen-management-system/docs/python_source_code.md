# Python Source Code Overview

1. **[`canteen_logic.py`](../canteen_logic.py)** — Order processor, successive queue engine, stock validator, daily sales summary, and ASCII stock gauge generator.
2. **[`database.py`](../database.py)** — SQLite schema for `menu_inventory` and `canteen_orders`.
3. **[`app.py`](../app.py)** — Flask POS counter, batch queue simulator, inventory restock page, and CSV export.
4. **[`tests/test_canteen.py`](../tests/test_canteen.py)** — Automated `unittest` suite.
