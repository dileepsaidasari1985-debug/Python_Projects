# Project Objectives

1. **Process Successive Customer Orders**: Iterate through sequential orders using loops and `(item_code, qty)` tuple unpacking.
2. **Calculate Itemized Bills**: Compute line totals, subtotal, 5% GST, and grand payable total accurately.
3. **Update Inventory & Reject Unavailable Quantities**: Deduct stock only for valid available items and reject insufficient/unknown/non-positive requests without corrupting stock.
4. **Summarize Daily Sales & Remaining Stock**: Report total revenue, order counts, low-stock alerts, ASCII stock bars, and CSV exports.
