# Problem Statement

## Case Study #100: Comprehensive Smart Campus Management Simulation

University campuses manage student profiles, attendance eligibility, academic marks, co-curricular event registrations, and shared lab/hall allocations across disconnected tools, creating duplicate bookings, missed attendance warnings, and fragmented reporting.

**Problem Statement:**
Design and implement a **Comprehensive Smart Campus Management Simulation** as a menu-driven Python system (accessible via both terminal `cli_menu.py` and a Flask + SQLite web dashboard) integrating student records, attendance tracking, marks & grading, capacity-enforced event registration, conflict-free resource allocation, and executive summary reporting using only core Python syllabus constructs.
