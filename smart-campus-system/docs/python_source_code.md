# Python Source Code Overview

1. **[`campus_logic.py`](../campus_logic.py)** — Core syllabus-compliant logic for all 6 campus modules and ASCII executive reporting.
2. **[`cli_menu.py`](../cli_menu.py)** — Interactive terminal `while True` menu-driven program.
3. **[`database.py`](../database.py)** — SQLite persistence for students, events, registrations, resources, and allocations.
4. **[`app.py`](../app.py)** — Flask web interface & CSV export.
5. **[`tests/test_campus.py`](../tests/test_campus.py)** — Automated `unittest` suite.
