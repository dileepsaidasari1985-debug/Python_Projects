# Project Objectives

1. **Provide a Menu-Driven Simulation**: Implement a continuous menu loop (`cli_menu.py`) alongside an interactive web navigation shell.
2. **Manage Student Records & Attendance**: Validate student tuples, calculate attendance percentages, and flag `< 75%` attendance shortages.
3. **Evaluate Marks & Grades**: Compute subject totals, averages, and letter grades from student score tuples.
4. **Enforce Event & Resource Rules**: Prevent duplicate event registrations, enforce event seat caps, block maintenance resources, and reject double-booked time slots.
5. **Generate Executive Campus Summaries**: Aggregate all modules into an ASCII executive report and CSV export.
