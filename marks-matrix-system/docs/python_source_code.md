# Python Source Code Overview

1. **[`matrix_logic.py`](../matrix_logic.py)** — 2D nested list traversal, row-wise and column-wise statistics, tuple tie-breaking, low-average alerts, and ASCII report generation.
2. **[`database.py`](../database.py)** — SQLite persistence for cohort marks and thresholds.
3. **[`app.py`](../app.py)** — Flask dashboard, matrix editor, custom sandbox, and CSV export.
4. **[`tests/test_matrix.py`](../tests/test_matrix.py)** — Automated `unittest` suite.
