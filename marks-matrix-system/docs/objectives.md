# Project Objectives

1. **Represent Cohort Marks as a 2D Matrix**: Store student records and subject scores in nested lists and tuples.
2. **Compute Row-Wise Statistics**: Calculate each student's total, average, minimum mark, maximum mark, grade, and pass/fail status.
3. **Compute Column-Wise Statistics**: Traverse columns via nested loops to obtain subject averages, highest/lowest scores, and pass rates.
4. **Identify Top Performers & Low-Average Subjects**: Rank students cleanly and highlight subjects whose average falls below `low_avg_threshold`.
5. **Persist & Export**: Support CRUD edits in SQLite, ASCII matrix summaries, and CSV exports.
