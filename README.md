# Python Activity-Based Learning — 10 Case Studies Portfolio

This repository contains **10 complete Python + Flask + SQLite projects** developed strictly using the assigned Python syllabus (*computational thinking, algorithms, flowcharts, pseudocode, variables, data types, operators, conditional statements, loops, strings, pattern generation, lists, nested lists, tuples, tuple operations, and tuple unpacking*).

Each project directory contains all **10 mandatory deliverables**:
- Problem Statement (`docs/problem_statement.md`)
- Objectives (`docs/objectives.md`)
- Assumptions (`docs/assumptions.md`)
- Algorithm (`docs/algorithm.md`)
- Flowchart (`docs/flowchart.md`)
- Pseudocode (`docs/pseudocode.md`)
- Python Source Code (`*.py` + `docs/python_source_code.md`)
- Test Cases (`tests/test_*.py` + `docs/test_cases.md`)
- Output Screenshots (`screenshots/*.png`)
- Conclusion (`docs/conclusion.md`)
