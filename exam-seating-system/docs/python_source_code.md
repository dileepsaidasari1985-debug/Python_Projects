# Python Source Code Overview

1. **[`seating_logic.py`](../seating_logic.py)** — Nested loop 2D seat matrix generator, reserved seat parser, alternate gap rules, capacity limiter, and ASCII hall map generator.
2. **[`database.py`](../database.py)** — SQLite storage for exam halls and saved seating plans.
3. **[`app.py`](../app.py)** — Flask application with interactive generator, hall management, saved plan viewer, and CSV export.
4. **[`tests/test_seating.py`](../tests/test_seating.py)** — Automated `unittest` suite.
